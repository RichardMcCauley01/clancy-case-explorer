# Commonwealth v. Lindsay Clancy: neutral case study (static site)

**Live site:** https://richardmccauley01.github.io/clancy-case-explorer/ · **Repo:** https://github.com/RichardMcCauley01/clancy-case-explorer

Open `index.html` by double-clicking it. It works offline from `file://`, and all libraries are vendored in `js/vendor/`. You can also serve the folder:

    python3 -m http.server 8765    # then open http://127.0.0.1:8765/

- `data/events.json`: events, each with datetime, precision, category, POV tags, status label, location and sources. It also holds the per-POV scene paths.
- `data/media.json`: outbound links to public media and documents, plus the list of items that are not public.
- `js/data.js`: the same data as a script, so the site runs without fetch under `file://`. Regenerate it with `python3 tools/build_data.py`.
- `js/scene.js` (three.js r149): approximate 3D reconstruction. Scroll or trackpad moves a damped target progress along one continuous Catmull-Rom path per POV. The view direction is slerped, and arrow keys and ticks glide to a step. This is an approximate layout based on testimony and reporting, not official floor plans.
- `js/timeline.js` (d3 v7): swimlane timeline with zoom, filters, search and a detail drawer.
- Deep links: `#scene?pov=lindsay|patrick|evidence&step=<event-id or number>`, `#timeline?zoom=all|history|day|minutes|trial&event=<id>`, `#media`, `#sources`, `#about`.

Compiled Sept. 29, 2026 from public sources only. Disputed claims are labeled. The site contains no images of the children and no scene or autopsy material.

## Publishing (GitHub Pages) and SEO

- SEO head tags (title, description, canonical, Open Graph/Twitter, robots, JSON-LD), the crawlable **Text version** (`#text`, also shown when JavaScript is off), `robots.txt` and `sitemap.xml` are all generated by `python3 tools/build_static.py [--url https://OWNER.github.io/REPO/]`. The URL is saved in `site.json`.
- Deploy or redeploy: `gh auth login` (one time, by the account owner), then `tools/deploy_github_pages.sh clancy-case-explorer`. The script rebuilds the data, sets the canonical URL, clones or creates the public repo, commits normally (no force push), enables Pages and waits for the site to go live.
- Updating after new developments (e.g., the Nov. 2, 2026 hearing): add events and sources in `tools/sources.py` and `tools/build_data.py`, set `lastUpdated` in `site.json`, then run the deploy script again.
- Google Search Console: add a URL-prefix property for the live URL. Either put the verification token in `site.json` → `googleSiteVerification` and redeploy, or drop the `googleXXXX.html` file into this folder and redeploy. Then submit `sitemap.xml`.
